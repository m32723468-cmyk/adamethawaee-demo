Réseaux sociaux & référencement

Publicité (pixels)

Pour suivre vos ventes depuis vos pubs Facebook/Instagram et TikTok. Les événements « Vue produit », « Ajout au panier », « Commande » et « Achat » sont envoyés automatiquement. Laissez vide si vous ne faites pas de publicité.

Meta : API Conversions & domaine

L'API Conversions envoie aussi les ventes à Meta depuis le serveur : les achats sont comptés même quand le pixel est bloqué (iPhone, bloqueurs de pub). Meta optimise mieux vos pubs et le coût par commande baisse. Les doublons pixel/serveur sont évités automatiquement.

⚪ Non activée (il faut l'ID du pixel + le token)

Comment obtenir le token et vérifier le domaine ?
  1. Token : Gestionnaire d'événements → votre pixel → Paramètres → section « API Conversions » → Générer un token d'accès. Copiez-le ici puis enregistrez.
  2. Tester : dans le Gestionnaire d'événements → Tester les événements, copiez le code (ex : TEST12345) dans « Code de test », puis cliquez sur « Envoyer un événement test ». Videz le code ensuite.
  3. Domaine (une fois le site en ligne sur votre domaine) : Paramètres de l'entreprise → Sécurité de la marque → Domaines → Ajouter adamethawaee.store → méthode « Balise meta » → collez la balise ici, enregistrez, puis cliquez sur « Vérifier » chez Meta.

Notifications des nouvelles commandes

Telegram

Recevez chaque nouvelle commande sur votre téléphone, en quelques secondes.

Comment activer Telegram (gratuit, 2 minutes) ?
  1. Installez Telegram et ouvrez la conversation avec @BotFather.
  2. Envoyez /newbot, choisissez un nom (ex : Adam Hawae Commandes) puis un identifiant finissant par bot.
  3. BotFather vous donne un token (ex : 123456:ABC-xyz…) : collez-le ci-dessous.
  4. Ouvrez votre nouveau bot et envoyez-lui « Bonjour ».
  5. Cliquez sur Trouver mon Chat ID, puis Envoyer un test.

Groupe avec sujets (recommandé)

Toutes les notifications rangées par thème dans un seul groupe, et votre équipe (ex : l'agent de confirmation) peut le rejoindre.

  • 🛍️ Nouvelles commandesChaque nouvelle commande avec la photo, le client et ses commandes précédentes—
  • ✅ Suivi des commandesConfirmations, annulations, expéditions… et qui l'a fait—
  • 📦 Produits & propositionsPropositions de l'équipe, produits créés, mis en ligne, épuisés—
  • ⭐ Avis & abonnéesNouveaux avis à valider et nouvelles abonnées—
  • 👥 Équipe & sécuritéConnexions, tentatives suspectes, comptes modifiés—
  • 📊 Rapport du jourLe bilan de la journée chaque soir—
Comment créer le groupe avec sujets ?
  1. Dans Telegram : Nouveau groupe (ex : « Adam & Hawae — Gestion »), ajoutez votre bot et les membres de l'équipe.
  2. Infos du groupe → Modifier → activez Sujets (Topics).
  3. Administrateurs → ajoutez le bot comme administrateur avec le droit Gérer les sujets.
  4. Écrivez /start dans le groupe, puis cliquez ici sur Trouver mon Chat ID (il commence par -100).
  5. Cliquez sur Créer les sujets : les 6 sujets apparaissent dans le groupe.

Sans groupe, tout continue d'arriver dans votre conversation privée avec le bot.

Le rapport (commandes, confirmations, retours, meilleures ventes, travail de l'équipe, commandes à rappeler) part dès la première visite sur le site après l'heure choisie.

E-mail

Comment activer l'e-mail avec Gmail (2 minutes) ?
  1. Sur votre compte Google, activez la validation en deux étapes (Sécurité).
  2. Ouvrez myaccount.google.com/apppasswords, créez un mot de passe d'application nommé « Boutique ».
  3. Google affiche un code de 16 lettres : collez-le dans « Mot de passe d'application » ci-dessous.
  4. Serveur : smtp.gmail.com, port 465, sécurité SSL, identifiant : votre adresse Gmail.
  5. Cliquez sur Envoyer un e-mail de test.

Une fois le site hébergé, vous pourrez utiliser l'e-mail de votre hébergeur (ex : contact@adamethawaee.store) avec ses paramètres SMTP.
