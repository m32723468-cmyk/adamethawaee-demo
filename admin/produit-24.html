Informations

Traductions

Le site s'affiche automatiquement dans la langue du téléphone de la cliente. Si un champ est vide, le texte français est utilisé.

Photos

La 1re photo est la photo principale. Glissez-déposez les photos pour changer l'ordre, ou utilisez ★ pour mettre une photo en premier. Pour un rendu comme sur la boutique, utilisez des photos sans arrière-plan (PNG/WebP transparent).

JPG, PNG ou WebP · 15 Mo max par photo · les photos sont enregistrées avec le produit quand vous cliquez sur « Enregistrer ».

Couleurs

Ajoutez chaque couleur disponible. Si une couleur a sa propre photo, choisissez-la : la photo changera quand la cliente clique sur la couleur. Pour des modèles numérotés (1, 2, 3…), cochez « Sans pastille ».

Le code couleur se tape au format #RRGGBB (ex : #602860), se choisit avec la pastille, ou se détecte sur le tissu avec 📷. Tapez un nom de votre palette : son code et ses traductions se remplissent tout seuls.
